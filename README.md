# JOSH — Echoes of the Shattered World

A fully playable 2D platformer with narrative quests across eight realms. Playable straight out of the box — no build step, no external downloads. Open `index.html` in any modern browser.

## How to play

- **Arrows / WASD** — move
- **Space / Up** — jump (double-jump available)
- **Down / S** — drop through platform
- **E** — talk to NPCs
- **Q** — open the quest log
- **R** — restart the current level

Collect all **Echo Fragments** in each realm to activate the exit, then reach it to progress. Complete every realm to restore the shattered world.

## What's inside

- 8 realms with distinct themes: Glade of Whispers → Crystal Depths → Sky Aerie → Ember Rift → Frost Peaks → Shadow Woods → Sunken Ruins → The Core
- 3 fragments per realm (24 total)
- NPC dialogue and per-realm quests with a quest log
- Stompable enemies, spike and lava hazards, checkpoints, particles
- Coyote time + jump buffering for polished platformer feel
- Persistent death counter and progress HUD
- Real Kenney CC0 pixel art assets under `assets/`

## Assets

All art is from Kenney's **Pixel Platformer** pack (CC0 1.0, https://kenney.nl/assets/pixel-platformer), bundled under `assets/`. Credit: Kenney (www.kenney.nl) — appreciated but not required.

## Tech

Plain HTML5 Canvas + vanilla JavaScript. No frameworks, no build tooling.
